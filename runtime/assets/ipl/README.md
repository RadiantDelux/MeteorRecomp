# Free IPL font assets

`font_japanese.bin` and `font_western.bin` are the free replacement IPL font
assets distributed by the Dolphin Emulator Project in `Data/Sys/GC/`.

- Upstream: https://github.com/dolphin-emu/dolphin
- License: GPL-2.0-or-later
- `font_japanese.bin` SHA-256: `38F9F59D505BC4E2D86B0196706195F33AD72B7FE9D029CF263072CDE19D044F`
- `font_western.bin` SHA-256: `4AD991BE2B0AA305F09B90A79FC50F57833B30B008890B5EF1336CC3D9D0BAE0`

These are not Nintendo IPL dumps. WiiCompiled maps them at the IPL font EXI
offsets so Wii/GameCube SDK `OSLoadFont` paths can run without redistributing a
copyrighted boot ROM.
